# RPG Starter (GameMaker)

My first GameMaker project — a top-down action RPG. I followed GameMaker's official
tutorial series and extended it.

## Features
- 4-direction player movement with walk/idle animations and tile collision
- Melee attack with slash effect
- Enemy AI with a state machine: idle → wind-up → lunge → cooldown
- Knockback and a poise system on enemies
- NPCs with a dialogue system (game pauses while talking)
- 2 rooms, with data carried between them
- Animated two-layer fog and drop shadows

## Built with
GameMaker, GML

## Controls
- Move: W A S D
- Attack: F
- Talk: E
